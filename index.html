How to run it

Sets: tap a bubble when you finish a set. Tap a checked bubble to select it, then use − / + if you missed or beat the reps. Tap a selected bubble to uncheck it. Sets − / + under the target adds or drops a set. Everything saves as you go.

Weight per set: the weight box sets the weight for the sets you haven't done yet, so change it before a set if you go up or down. To fix a set you already did, tap its bubble, then change the box. When weights differ, each bubble shows its weight. Progression goes off your heaviest set.

Workout time: Start workout at the top, or it starts itself when you check your first set. End it when you're done; you'll get a prompt once every set is checked.

Progression: each set's target is last time's reps +1, up to the top of the range. Miss a set and it drops back to what you did. When every set hits the top, the weight goes up by that lift's jump and reps reset to the bottom. You can always change the weight box; jump sizes and the Smith bar weight are in Settings.

First time on a lift: it starts at a suggested weight. If set 1 beats the top of the range by 2+, go up one jump; if you can't reach the bottom, drop one.

Smith lifts: enter the plates on one side. The bar is added for you.

Effort: stop most sets 1–2 reps short of failure; take the last set of each exercise to failure.

Rest: a rest timer starts on the card when you check a set, except the last set of an exercise: 2:30 on the big lifts, 1:30 on everything else; −15 / +15 to change it. Checking the last set minimizes the exercise; tap it to open it again. The clock at the top still works by hand.

Deload: every 6–8 weeks, cut the sets in half for a week.
