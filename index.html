Push Pull Legs Log

Pick today's session. Last time's numbers show on each exercise.

How to run it

Effort: stop most sets 1–2 reps short of failure; take the last set of each exercise to failure.

Log: the weight you used and the reps on your weakest set (the Reps box). When that set hits the top of the range, the card says Add weight.

Rest: 2–3 minutes on the first big lifts of each day, about 90 seconds on the rest.

Deload: every 6–8 weeks, cut the sets in half for a week.
